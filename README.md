# DevTree

DevTree is a web application inspired by LinkTree that allows users to create a personalized page containing links to their social media profiles and other online platforms.

The project was developed as part of a Fullstack development course focused on building web applications with Node.js, TypeScript, Express, and React.

## Overview

DevTree allows users to create an account and manage their own personalized collection of links.

Main features include:

* User registration and authentication.
* Creation and management of personalized links.
* Support for popular social media platforms such as Instagram, YouTube, Facebook, and others.
* User profile customization.
* File uploads.
* Different visual themes for personalized pages.
* Data management using React Query.

## Technologies

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* React Query

### Backend

* Node.js
* Express

### Database

* MongoDB

## Project Context

DevTree was developed as the first project of a Fullstack development course covering modern web application development with Node.js and TypeScript.

The project was used to practice concepts including frontend development with React, backend development with Express, authentication, data fetching and state management with React Query, file uploads, and database integration with MongoDB.
